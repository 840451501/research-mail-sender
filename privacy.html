隐私政策

本政策适用于个人自用的 Research Mail Sender 本地发送模块及其说明网站。维护者为 GitHub 用户 840451501（Perry2077），联系邮箱为 perrychen2077@gmail.com。

访问的数据和用途

程序获取授权账号的邮箱地址与验证状态，用于核对发件身份；使用 OAuth 访问令牌和刷新令牌调用 Google API。程序处理用户指定的收件人、主题、正文、PDF 文件、文件名、字节数和 SHA-256 指纹，以组装邮件、校验附件并防止重复发送。程序保存 Gmail 返回的邮件标识、发送时间及运行状态，以核对执行结果。

发送模块申请 gmail.send 和账号邮箱识别权限，不申请邮箱读取权限。用户可能另行授权独立的邮件连接器查询已发送记录；相关查询由该连接器及其服务提供商依各自政策处理。

数据存储与保护

OAuth 凭证保存于用户 Mac 的 macOS 钥匙串；运行状态、附件指纹和发送回执保存于用户控制的本地目录。源报告仍保留在用户自己的存储位置。程序通过 HTTPS 与 Google 通信，不在普通日志中记录完整凭证。此公开网站及其源码仓库不包含邮件正文、报告文件、访问令牌或刷新令牌。

传输与共享

用户指定的邮件内容和附件会传输至 Google，并由 Gmail 投递给指定收件人。收件人可依其邮箱规则保存邮件；相关处理适用 Google 与收件方邮箱服务的政策。应用维护者不出售 Google 用户数据，不将其用于广告或训练通用人工智能模型。

Research Mail Sender 对从 Google API 接收的信息的使用和传输遵守 Google API Services User Data Policy，包括 Limited Use 要求。

保留、撤销与删除

本地凭证和运行记录保留至用户删除或撤销。用户可在 Google 账号的第三方连接设置中撤销访问权限，并在本机删除此应用的钥匙串条目和运行记录。撤销授权会停止后续 API 调用，不会自动删除已发送邮件或收件人保存的副本；这些邮件需要在相应邮箱中处理。源文件的保留由用户自行管理。

网站访问

本说明网站使用 GitHub Pages 托管，不添加分析脚本、广告或自建追踪 Cookie。GitHub 可能为安全及服务运行记录访客 IP 等数据，具体见 GitHub 隐私声明。

政策变更与联系

数据处理方式变更时会更新本页及生效日期。需要扩大 Google 访问权限时，应先取得用户授权。有关隐私、撤销或删除的问题，请联系 perrychen2077@gmail.com。
